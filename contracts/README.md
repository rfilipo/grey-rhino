# Contracts

Contracts in this case are created through the kob flow (mentor / shell), which
generates `contracts/<id>/contract.json`, `contract.md` and `quiz.md`. This
directory starts empty on purpose — contracts are born in the workflow, not
hand-written here.

Seed contracts for this operation (see the blueprint):

- **relaunch-gate** — the members' formal approval of the governed relaunch.
- **weekly-cycle** — the standing editorial-week contract.
